# ProyectoGestionAcademica

Este proyecto se desarrolla para la última entrega de "Teoría de Bases de Datos", con el propósito de interiorizar aprendizajes sobre el uso de bases de datos Relacionales y no relacionales. 

En este gestor de un sistema universitario, se va a usar MySQL para guardar datos transaccionales (estudiantes, matrículas), mientras que se usará MongoDB para datos no estructurados (logs, preferencias)
